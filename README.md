# Bot Win Bac Bo — landing page

Site estático pronto para GitHub + Netlify.

## Publicar
1. Suba TODO o conteúdo desta pasta para o repositório no GitHub.
2. Na Netlify: "Add new site" → "Import an existing project" → escolha o repositório.
3. Build command: deixar vazio. Publish directory: deixar raiz (`.`).
